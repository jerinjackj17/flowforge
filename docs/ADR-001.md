# ADR-001: LangGraph over Temporal

Status: accepted, 2026-10-13

## Context

The workflow needs persisted checkpoints, retries with backoff, human
approval gates, and a live demo on free hosting (Vercel serverless plus
Upstash Redis).

## Options

**Temporal.** The gold standard for durable execution. Needs a Temporal
cluster or Temporal Cloud next to the app. Self-hosting on free tiers is
painful, Cloud is overkill for a demo. The programming model is the right
idea, but the operational weight breaks the one-click deploy goal.

**LangGraph.** DAG-first, checkpoints to any store (Redis here),
`interrupt()` for human-in-the-loop, runs anywhere Python runs including
serverless. Less operationally complete than Temporal (no built-in worker
fleet), but the checkpoint plus resume semantics are exactly what the demo
needs.

## Decision

LangGraph with a Redis checkpointer. The durability story, kill the process
and resume from the checkpoint with nothing executing twice, is fully
demonstrable, and the whole system deploys as one Vercel project.

## Consequences

Retries are a manual loop in the node, not framework retry policies, so the
backoff shows up in the run log. Demo-driven choice; a production port would
use declarative retries.

Human approval is `interrupt()` plus a web inbox. The Slack webhook is a
documented extension, not the default, to keep the demo self-contained.

If this ever needs multi-worker scale-out or schedules, revisit Temporal.
